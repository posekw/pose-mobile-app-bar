# Pose Mobile App Bar - دليل المميزات

## 🎨 التصميم والمظهر

### تصميم Glassmorphism العصري
- تأثير زجاجي احترافي مع ضبابية قابلة للتخصيص
- شفافية قابلة للتحكم الكامل
- خلفية بأي لون تختاره

### نظام ألوان متقدم
- **لون الأيقونات**: تحكم منفصل في لون جميع الأيقونات
- **لون النصوص**: تحكم منفصل في لون النصوص تحت الأيقونات
- **لون التفعيل**: لون مميز للصفحة النشطة الحالية
- **لون الفواصل**: تخصيص لون الخطوط الفاصلة بين الأزرار

### الفواصل بين العناصر
- خطوط فاصلة أنيقة بين أزرار القائمة
- قابلة للتفعيل أو التعطيل
- لون قابل للتخصيص بالكامل

---

## 📱 عناصر القائمة

### حتى 5 عناصر قابلة للتخصيص الكامل
كل عنصر يحتوي على:
- **الأيقونة**: اختيار من مكتبة Dashicons الكاملة (أكثر من 300 أيقونة)
- **النص**: تسمية مخصصة باللغة العربية أو الإنجليزية
- **الرابط**: ربط بأي صفحة في موقعك

### كلاسات CSS فريدة لكل عنصر
- كل زر له كلاس خاص: `.pmab-item-1`, `.pmab-item-2`, `.pmab-item-3`, إلخ
- يسمح بتخصيص كل زر بشكل منفصل عبر CSS المخصص

---

## 🎯 التحكم في إظهار/إخفاء عناصر الموقع

### خيارات الإخفاء المتقدمة
- ✅ **إخفاء الهيدر الرئيسي**: Logo والقائمة العلوية
- ✅ **إخفاء الهيدر السفلي**: شريط القائمة السفلي (Bottom Row)
- ✅ **إخفاء الفوتر**: تذييل الموقع
- 📝 **محددات CSS مخصصة**: إخفاء أي عنصر آخر بكتابة CSS Selector الخاص به

### وضع التطبيق الأصلي (Native Mode)
- تفعيل تجربة تطبيق كاملة
- يخفي الهيدر والفوتر تلقائياً
- مثالي لتحويل موقعك إلى تطبيق ويب

> **ملاحظة مهمة**: لا يتم إخفاء أي شيء افتراضياً - أنت من يتحكم بالكامل!

---

## 🎨 CSS مخصص (Custom CSS)

### صندوق CSS حر للتخصيص الكامل
- أضف أي قواعد CSS تريدها مباشرة من لوحة التحكم
- لا حاجة لتعديل ملفات القالب

**مثال**: تلوين زر الجاليري بلون ثابت:
```css
.pmab-item-2 .label {
    color: #ff0055 !important;
}
```

**مثال**: إخفاء النص من زر معين وإبقاء الأيقونة فقط:
```css
.pmab-item-3 .label {
    display: none;
}
```

## ⚙️ الإعدادات المتقدمة

### التحكم في الأبعاد والمسافات
- **الارتفاع**: ضبط ارتفاع شريط التنقل (القيمة الافتراضية: 65px)
- **المسافة الآمنة**: مسافة إضافية للأجهزة ذات الشاشات المنحنية (iPhone X وما بعده)
- **الضبابية (Blur)**: درجة التمويه الزجاجي (0-20px)
- **الشفافية (Opacity)**: درجة شفافية الخلفية (0-1)

### زر إعادة ضبط المصنع
- استعادة جميع الإعدادات الافتراضية بنقرة واحدة
- مفيد جداً عند التجربة والخطأ
- يحذف جميع التخصيصات ويعيد القيم الأصلية

---

## 📲 التوافق والأداء

### للأجهزة المحمولة فقط
- يظهر تلقائياً على الهواتف الذكية والأجهزة اللوحية
- مخفي تماماً على أجهزة الكمبيوتر المكتبية
- يعمل على جميع المتصفحات الحديثة

### كشف الصفحة النشطة الذكي
- تمييز تلقائي للصفحة الحالية بلون مختلف
- يعمل مع الصفحة الرئيسية والصفحات الفرعية
- يدعم الروابط المخصصة والمعقدة

### أداء محسّن
- استخدام CSS Variables لتحسين الأداء
- كود نظيف ومنظم
- لا يؤثر على سرعة تحميل الموقع

## 📖 كيفية الاستخدام

### 1. التثبيت
- قم بتثبيت الإضافة عبر WP Pusher
- أو ارفع الملفات يدوياً إلى مجلد `/wp-content/plugins/`

### 2. التفعيل
- فعّل الإضافة من لوحة تحكم WordPress
- اذهب إلى **الإعدادات > Mobile App Bar**

### 3. التخصيص
1. فعّل الإضافة من الخيار الأول
2. اختر الألوان المناسبة لموقعك
3. أضف عناصر القائمة (حتى 5 عناصر)
4. خصص خيارات الإخفاء حسب حاجتك
5. احفظ التغييرات

### 4. الاختبار
- افتح موقعك من الهاتف المحمول
- تأكد من ظهور شريط التنقل في الأسفل
- جرّب التنقل بين الصفحات

## 🆘 الدعم والمساعدة

### الأسئلة الشائعة

**س: لماذا لا يظهر الشريط على موقعي؟**
ج: تأكد من:
- تفعيل الإضافة من الإعدادات
- فتح الموقع من جهاز محمول (أو وضع المحاكاة في المتصفح)
- إضافة عنصر واحد على الأقل

**س: كيف أخفي الهيدر السفلي فقط؟**
ج: من **Visibility Controls**، فعّل خيار "Hide Header Bottom Row"

**س: كيف أجعل زر معين بلون ثابت؟**
ج: استخدم حقل **Custom CSS** وأضف:
```css
.pmab-item-N .label { color: #YOUR_COLOR !important; }
```
(استبدل N برقم الزر، مثل 2 للزر الثاني)
