# Pose Mobile App Bar 📱

A premium, native-app like bottom navigation bar for WordPress. Make your mobile website feel like a real app with beautiful Glassmorphism design and easy customization.

![License](https://img.shields.io/badge/license-GPLv2-blue.svg)
![Version](https://img.shields.io/badge/version-3.1.0-green.svg)

## Features 🚀

- **Native App Mode**: Hides the default header/footer on mobile for a full app-like experience.
- **Glassmorphism Design**: Beautiful frosted glass effect with customizable blur and opacity.
- **Customizable**: Change colors, icons (Dashicons), and labels easily.
- **Smart Active States**: Automatically highlights the current page.
- **Lightweight**: Pure CSS/PHP, no heavy JavaScript libraries.

## Installation

1. Upload the `pose-mobile-app-bar` folder to the `/wp-content/plugins/` directory.
2. Activate the plugin through the 'Plugins' menu in WordPress.
3. Configure the settings under **Settings > Mobile App Bar**.
